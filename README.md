## 🚀 Getting Started

### Prerequisites

- Python 3.x
- Jupyter Notebook or JupyterLab
- NumPy
- Scikit-learn
- Otter-Grader (for quiz auto-grading)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/t-ed-c/DSAIL.git
cd DSAIL
```

2. Install required packages:
```bash
pip install numpy scikit-learn otter-grader jupyter
```

3. Launch Jupyter Notebook:
```bash
jupyter notebook
```

### Running the Quiz

1. Open `Desktop/m3_registration_quiz/m3_registration_quiz.ipynb`
2. Run cells in order from top to bottom
3. Implement solutions for each question
4. Use `grader.check('qN')` to verify your answers
5. Run the final export cell to generate your submission file
6. Upload the generated `.zip` file to the Google Form

## 📝 Tips for Success

- **Read Carefully:** Ensure you understand each question before coding
- **Test Incrementally:** Build solutions step-by-step and test frequently
- **Use NumPy Functions:** Leverage `np.mean()`, `np.std()`, `np.linalg.norm()`, etc.
- **Round Appropriately:** Pay attention to decimal place requirements (e.g., 4 decimal places)
- **Don't Hardcode:** Always compute results programmatically
- **Save Before Export:** Save your notebook before running the final export cell
